# Hands of Heritage

This project is a premium Next.js website prototype for a handcrafted gifting brand.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open http://localhost:3000 in your browser.

## Stack

- Next.js 14
- React 18
- TypeScript
- Framer Motion
- GSAP
